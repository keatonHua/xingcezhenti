# 北京公务员考试（京考）行测真题整理

本目录仅整理**北京市**公务员考试行测真题，按年份刷题；每个年份（试卷）内**题目**与**答案**分开存放，题目文件中不含答案、对错标记与解析。内容全部由仓库已有的北京相关原题副本生成（只做拆分与相对路径调整，未改写题干/选项/解析）；原有文件未做任何改动，图片继续引用根目录 `90-图片/`。

## 目录结构

```
北京公务员考试行测真题整理/
├── README.md
└── <年份>/
    └── <试卷>/                 # 统一卷 / 乡镇卷 / 区级及以上卷 / 定向选调
        ├── 题目/<模块>.md      # 仅题干+选项，按原题序
        └── 答案/<模块>.md      # 答案速查表 + 逐题答案与官方解析
```

- 题型分类依据：沿用来源仓库自身的模块划分（01-政治理论、02-常识判断、03-言语理解与表达、04-数量关系、05-判断推理、06-资料分析）；每道题标题处的 `qid … · 子题型` 为来源题库的细分标签。
- 题目与答案对应：题目文件与答案文件**同名**，题号（`第 N 题`）、顺序均与原文件一致，答案文件顶部有「答案速查」表。
- 做题建议：打开 `题目/<模块>.md` 刷题，完成后对照 `答案/<模块>.md`。
- 图片：以相对路径引用仓库根目录的 `90-图片/`，需在仓库内查看。
