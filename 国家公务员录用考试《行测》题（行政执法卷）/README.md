## 设计说明

- 题目按 `年份 / 题型类别 / 题目.md` 组织，便于按年份和题型检索；
- 答案按 `年份 / 题型类别 / 答案.md` 组织，确保题目和答案分离；
- 生成脚本会自动扫描现有模块文件并批量按这个规则拆分；
- 生成前后都保留原始真题源文件，避免丢失信息。

## 生成方式

在仓库根目录执行：

```bash
python3 "国家公务员录用考试《行测》题（行政执法卷）/scripts/generate_split_by_year_and_type.py"
```

脚本会自动按以下规则处理：

- 识别年份：例如 `2025年国家公务员录用考试《行测》题（行政执法卷网友回忆版）`
- 识别题型：例如 `01-政治理论`、`02-常识判断`、`03-言语理解与表达`
- 拆分内容：从 `**答案**：` 之前提取题目，之后提取答案与解析
- 输出到 `国家公务员录用考试《行测》题（行政执法卷）/{年份}/{题型}/`
